  <h1 id="build-title">How I Built This Site</h1>
  <p>This site was scaffolded as a Jekyll project intended for GitHub Pages. The structure includes a shared layout, theme variables in CSS, and dedicated content pages for each communication lens.</p>
  <p>The automation layer uses GitHub Actions to build the site on every push to the <code>main</code> branch. The configuration sets the correct URL and repository base path so local and hosted builds resolve links correctly.</p>
  <p>An AI coding agent helped generate the initial website skeleton, accessibility-oriented markup, starter copy, and documentation so the author can focus on writing and refining original analysis.</p>
